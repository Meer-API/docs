### 1. Get an API key

Request one at [meerapi.com](https://www.meerapi.com/).

### 2. Check a number

URL-encode the number (`+` becomes `%2B`):

<RequestExample>

```bash
curl --request GET \
  --url 'https://api.meerapi.com/check_phone_number?phone_number=%2B14155552671' \
  --header 'Authorization: Bearer <YOUR_API_KEY>'
```

</RequestExample>
